# Requisiti

| Componente | Versione |
| --- | --- |
| Minecraft | 26.2 |
| NeoForge | 26.2.0.88 o successiva |
| Java | 25 |

QRM va installato **sia sul server sia sui client**: la rete e i registri devono corrispondere. Client e server devono avere la stessa versione di QRM e, se presente, della banca.

Il database predefinito è SQLite e non richiede nulla di installato. Le istruzioni di installazione sono in [Installazione](../server-owner/installazione.md).
