# Requisiti

| Componente | Versione |
| --- | --- |
| Minecraft | 26.2 |
| NeoForge | 26.2.0.88 o successiva |
| Java | 25 |

QRM va installato sul **server**. Il client è **facoltativo**: chi non lo installa entra comunque e usa i comandi; chi lo installa ha in più l'HUD, l'hub, la schermata Personaggi e, per lo staff, il pannello. Un client che ha QRM deve avere **la stessa versione** del server.

Il modulo banca registra blocchi e item, quindi, se lo installi, serve **anche sui client**, alla stessa versione.

Il database predefinito è SQLite e non richiede nulla di installato. Le istruzioni di installazione sono in [Installazione](../server-owner/installazione.md).
